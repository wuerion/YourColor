# Colorometría

## Descripción

Este proyecto se centra en la colorimetría, el estudio y la medición de los colores. Aquí encontrarás herramientas y recursos para trabajar con colores de manera precisa y eficiente.

## Instalación

Para instalar las dependencias necesarias, ejecuta el siguiente comando:

```bash
npm install
```

## Uso

Para iniciar la aplicación, utiliza el siguiente comando:

```bash
npm start
```

## Estandar de Mensajes de Commit

En este proyecto utilizamos **Conventional Commits** para mantener un historial claro y organizado. Cada mensaje debe seguir la siguiente estructura

'tipo de descripcion breve en minusculas'

### Tipos de commit aceptados

- **feat**: una nueva caracteristica para el usuario (ej. un nuevo componente).
- **fix**: correcion de un fallo o error visal.
- **style**: cambios que no afectan la logica (espacios, formato, clases de tailwind).
- **refactor**: cambio en el codigo para mejorarlo, pero no añade funciones ni corrige bugs.
- **docs**: cambios solo en la documentacion, instalacion (README, comentarios).
- **chore**: tereas de configuracion, instalacion de paquetes o cambios en el build.
- **perf**: cambios de codigo que mejoran el rendimiento.

### Reglas importantes:

1. **espacio obligatorio**: simepre debe haber un espacion despues de los dos puntos('feat: mensaje').
2. **minusculas**: la descripcion debe comenzar en minusculas.
3. **imperativo**: escribe el mensaje como una orden (ej. 'add' en lugar de 'added' o 'agrega' en lugar de 'agrego').
4. **longitud maxima**: el mensaje tiene que ser menor o igual a una longitud maxima de 72 catacteres.

> **nota:** el proyecto cuenta con 'commitlint' y 'husky', si el mensaje no cumple con este formato, el commit sera rechazado automaticamente.
